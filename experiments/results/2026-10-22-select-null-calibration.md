# `leaf_model="select"` null-selection calibration

## 要約（10行）

1. 実行モードは **quick**、学習行数は [2000]、seed は [0, 1]。
2. 固定 margin=0.01 の K=1→7 による pooled null 選択率変化は 0.80% → 4.30%。
3. null 選択率は実葉サイズ別に集計し、小葉の一部は `min_samples_linear` により自動的に constant となる。
4. 凍結判定を全セルで満たす既定値候補は **該当なし（既定変更なし）**。
5. 判定は null≤5%、A/B 真ブロック回収≥80%、各セルの holdout が連結 ridge 以下、の同時条件。
6. null-only の追試候補は **per-tree null q95**、平均 holdout 差は bin -0.0011 ± 0.0042, reg -0.0020 ± 0.0013。
7. per-tree null q95 は各木の各葉における偽ブロック最大 LOO 改善の95分位を使う。
8. `sqrt` 規則の K は偽ブロック数で、`c*sqrt(log(K+1)/n_leaf)` を実葉サイズごとに適用した。
9. `d` は凍結仕様どおり4固定であり、次元依存はこの実験から識別できない。
10. 結論は合成分布内の較正であり、実データ既定値の変更には追加検証が必要。

## 実行条件

- command: `OMP_NUM_THREADS=1 PYTHONPATH=src python3 experiments/select_null_calibration.py --quick`
- wall time: **60.4 s**
- n_estimators=25, num_leaves=15, learning_rate=0.1
- n_rows=[2000], seeds=[0, 1], d=4
- K(false)=[0, 1, 3, 7], margin=[0.0, 0.01, 0.03, 0.1], min_samples_leaf=[20, 100]
- objective: regression (RMSE) / binary logistic (logloss)
- router: raw 6 columns only; all expert columns are `leaf_only_features`

`n_rows` は学習行数。holdout は独立生成した `max(1,000, n_rows/4)` 行。 quick は K・margin・min-leaf・目的・較正规則を保ち、n_rows、seed 数、木数だけを削減した。

## データ生成と集計定義

`route_0 < -0.35` を A、`route_0 > 0.35` を B、その間を C とした。 A では T1、B では T2 の4次元線形信号を植え、C は局所線形信号なし。 P1 は T1 の行置換、N1... は独立標準ガウス。回帰には Gaussian noise、二値には planted logit から Bernoulli draw を用いた。

葉の地域は、その木で当該葉へ route された学習行の多数決。真回収率は A→T1 と B→T2 の合算、C constant 率は多数地域 C の葉を分母とする。両者は select が線形 fit を許す `n_leaf >= 2*min_samples_leaf` の葉だけを対象とし、null 選択率の分母は全葉。 seed 間 std は sample std（seed 数が1の場合のみ0）で、表の `±` はすべてこの定義。

**判定: 該当なし（既定変更なし）。** 各候補について seed 平均を design cell ごとに計算し、K>0 セルの最大 null 率、全セルの最小回収率、全セルの最大 holdout 差を使った。 pooled mean だけで悪いセルを隠さない保守的判定である。

正式な既定値変更は提案しない。null≤5% だけを満たす候補のうち回収率が最も高い **per-tree null q95** を full-grid 追試候補とするが、回収率と worst-cell holdout 条件を満たさないためライブラリ既定にはできない。

## 前提の誤り・限界

- Goal は d の関数を求めるが、凍結要因では d=4 しか指定されていない。したがって d 依存は推定不能。
- K は冒頭では全ブロック数とも読めるが、凍結要因の記述に従い偽ブロック数 0/1/3/7 と解釈した。総候補数は K+2。
- 葉領域は ground-truth region の多数決であり、境界をまたぐ葉を除外していない。purity の低い葉は回収率を下げ得る。
- 同じ木の q95 は高々15葉から推定されるため離散的で不安定。別 calibration split を使う規則ではない。
- boosting 後半の Newton target は初期の planted response と異なるため、真回収率100%は期待しない。
- quick report は5 seed・20,000行・100木の確証ではなく、スクリプトの full mode が凍結グリッドを実装する。
